Este repositório foi criado para armazenar e organizar os algoritmos que estudo e desenvolvo no meu dia a dia.

* JavaScript (ES6)
* C

## 📁 Organização do Repositório
O projeto está dividido nas seguintes pastas:
* `/aulaArquivos`: Todos os códigos utilizados nas aulas de Arquivos. 

## 🛠️ Como Compilar e Executar os Códigos em C

Para rodar os algoritmos de C na sua máquina, você precisará de um compilador (como o GCC). Siga os passos no terminal:

1. Clone o repositório:
```bash
git clone https://github.com
```

2. Entre na pasta do algoritmo:
```bash
cd seu-repositorio/aulaArquivos
```

3. Compile o arquivo `.c` gerando um programa executável:
```bash
gcc copia1.c -o copia1
```

4. Execute o programa gerado:
* **No Windows:**
```bash
copia1.exe
```
* **No Linux ou Mac:**
```bash
./copia1
```
